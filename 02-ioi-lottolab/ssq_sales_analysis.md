# 双色球销售规模与一等奖注数实证分析

数据范围：2003001～2026079，共3476期。中彩网销售/奖级记录与本地开奖号码逐期匹配，号码不一致0期。

## 全历史统计

- 双色球一等奖号码空间：17,721,088种。
- 平均销售额：288,577,747元，相当于144,288,874个2元基本投注。
- 实际一等奖共27,793注；按销售量和均匀开奖计算的期望为28,302.3注，实际/期望=0.982。
- 实际0注一等奖325期，非0注3151期，非0比例90.650%。
- 若把每个等效投注近似为独立随机选号，模型期望0注期数仅84.6期；实际更多，说明重复号码、多倍投注和选号集中使独立假设偏乐观。
- 一等奖注数均值7.996、方差102.591，明显过度离散；中奖彩票注数不能直接当作独立中奖人数。
