# Contributing to IOI-LottoLab

感谢你愿意改进 IOI-LottoLab。项目优先接受可复现、可验证、不会夸大预测能力的贡献。

## 开始之前

1. 先搜索现有 Issue，避免重复工作。
2. 涉及算法效果的改动，请明确基线、固定预算、数据区间和目标指标。
3. 目标期开奖数据不得进入当期训练或参数选择。
4. 不要把结构指数、历史频率或回测命中率称为未来中奖概率。

## 本地开发

```bash
python -m venv .venv
python -m pip install -r requirements.txt
python -m unittest discover -p "test_*.py"
```

启动 Web 仪表盘：

```bash
python web_app.py
```

## Pull Request 建议

- 保持改动范围聚焦。
- 描述为什么需要改动，以及用户或研究流程会受到什么影响。
- 附上执行过的测试和回测命令。
- 新算法至少包含等概率或现有生产算法基线。
- 报告失败实验；负结果同样有价值。
- 不提交本地数据库、预测审计库、模型状态、日志、EXE 或浏览器临时目录。

## 统计与回测原则

- 使用严格 walk-forward 或明确隔离的 holdout。
- 固定每期成本后再比较命中率或 ROI。
- 同时报告绝对差异、样本量和不确定性。
- 多模型筛选应进行多重检验校正。
- 头奖事件应以精确组合概率为主要依据，避免从极少实际样本得出强结论。

## 行为准则

保持尊重、具体和可验证。不要宣传“稳赚”“包中”或其他误导性承诺。
