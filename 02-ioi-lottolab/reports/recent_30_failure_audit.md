# 最近30期实盘预测失奖审计与高奖模式改造

生成日期：2026-07-18

## 结论

现有算法的主要问题不是“号码池完全没碰到开奖号码”，而是五注组合把已
碰到的号码拆散，以及后区命中没有落到前区最高的同一注。

### 双色球（2026052—2026081）

- 30期中奖7期、未中奖23期。
- 五注号码池平均覆盖5.43个实际红球，但单注平均最高只有2.17个。
- 30期的号码池都覆盖到至少4个实际红球，单注却没有一期达到4红。
- 蓝球覆盖7期，但蓝球与当期最高红球注对齐仅2期。
- 23个未中奖期中：
  - 18期（78.3%）：前区集中度不足，同时蓝球漏失；
  - 5期（21.7%）：单注已有3红以上，但蓝球没有落在同一注。

旧版“30红球零重叠”适合扩大号码池，却会稳定地产生“小范围命中分散”
的结果。v14改为从随机合法候选池选择五注，任意两注最多重叠3红，让
模型偏好的核心号码可以在多注出现，同时保持五注互不相同。

最近30期严格走期对比：

| 指标 | 旧30红覆盖 | v14高奖重叠 |
|---|---:|---:|
| 至少4红期数 | 1/30 | 2/30 |
| 至少3红期数 | 6/30 | 7/30 |
| 同注联合强度均值 | 44.03 | 50.57 |
| 5红/大奖 | 0 | 0 |

### 大乐透（2026051—2026080）

- 30期中奖8期、未中奖22期。
- 五注号码池平均覆盖2.77个实际前区，单注平均最高只有1.67个。
- 后区覆盖24期，但后区与最高前区注对齐只有13期。
- 22个未中奖期中：
  - 9期（40.9%）：后区命中，但落在低前区注；
  - 7期（31.8%）：同注前后区组合仍未达到奖级；
  - 6期（27.3%）：前区不足3个，同时后区漏失。

旧优化器曾把“后区覆盖98%、中奖率34%”的方案压过“后区覆盖78%、
中奖率36%”的基线，原因是评分直接奖励后区覆盖率。v6已经删除这项
错误奖励，改用同注联合强度、4前区、3前区+2后区、5前区和高奖事件
作为晋升条件。本轮30期自学习没有让挑战方案通过闸门，因此保留联合
强度更高的100期训练基线，而不是为了版本升级强行采用较差配置。

## 新的“随机五注”流程

1. 用目标期号生成可复现随机种子，先探索大量合法随机组合。
2. 只使用目标期开奖前的数据对候选进行结构、频率和低频形态评分。
3. 双色球允许最多3红重叠，从“最大号码池”切换为“高奖集中＋有限分散”。
4. 大乐透按同一注的前后区联合表现选参数，不再用后区任意覆盖率冒充改进。
5. 每期开奖后结算锁定票组，最近30期滚动重选参数；挑战配置必须通过
   高奖晋升闸门，否则继续使用表现更强的基线。
6. 台账后区统一显示“未中 / 中1个 / 中2个”；其中大乐透“中2个”表示
   五注后区号码池覆盖了两个实际后区，单注最高命中数另行保留。

本次30期回测支持的是“减少命中拆散、提高高阶命中代理指标”，尚未在这
30期中出现5红或头部奖级，因此没有把大奖概率写成已经得到实盘验证的提升。
